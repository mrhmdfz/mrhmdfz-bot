# 🟢 MRHMDFZ WhatsApp Bot

[![Node.js](https://img.shields.io/badge/Node.js-v22.15.0-green)](https://nodejs.org/) 
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow)](LICENSE)
[![Platform](https://img.shields.io/badge/Platform-WhatsApp-blue)](https://www.whatsapp.com/)

MRHMDFZ adalah **WhatsApp selfbot** berbasis [Baileys](https://github.com/WhiskeySockets/Baileys) dengan fitur modular, hot reload, dan sistem stiker. Dirancang untuk **akun pribadi** dengan kemudahan penambahan command baru.
